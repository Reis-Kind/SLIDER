# Marpスライド（約11分）

1. ZIPを展開し，`marp_bnn_ga`フォルダーをVS Codeで開きます．
2. 拡張機能「Marp for VS Code」を入れます．
3. `slides.md`を開き，Marpのプレビューを表示します．

- 本編17枚．発表原稿と時間配分は，各スライド末尾のHTMLコメントに入っています．
- 原稿だけ読みたい場合は `speaker_notes.md` を開いてください．
- 図とグラフは `images/` 内のPNGを参照します．フォルダー構成を保ってください．
- CNN・GAの図はSVG版も同梱しています．図を変更する場合に使えます．
- 交叉の青・橙は親1・親2に対応します．正答率のグラフは黒が学習用，赤がテスト用です．
- 結果と実験条件は元資料に基づきます．GAの個体評価図の正答率だけは説明用の例です．
- 発表時間は目安です．通し練習で約11分になるように調整してください．
